# 📚 Guild of Monster Girls — Encyclopedias & Databases / Энциклопедии и Базы Данных

В этой папке собраны полные энциклопедии и структурированные базы данных по персонажам и предметам игры **Guild of Monster Girls** на трех языках:
- 🇷🇺 **Русский (`_RU` / `_ru`)**
- 🇬🇧 **English (`_EN` / `_en`)**
- 🇨🇳 **中文 / Chinese (`_CN` / `_cn`)**

## 👥 1. Персонажи / Characters / 角色系统 (204 Heroines & Skins)

### 🇷🇺 Русский язык:

- [**`game_characters_database_ru.json`**](./game_characters_database_ru.json) — Структурированная JSON-база данных персонажей на русском языке.

### 🇬🇧 English:
- [**`GAME_CHARACTERS_ENCYCLOPEDIA_EN.md`**](./GAME_CHARACTERS_ENCYCLOPEDIA_EN.md) — Complete character encyclopedia in English.
- [**`game_characters_database_en.json`**](./game_characters_database_en.json) — Structured JSON database of all 204 monster girls in English.

### 🇨🇳 中文 (Chinese):
- [**`GAME_CHARACTERS_ENCYCLOPEDIA_CN.md`**](./GAME_CHARACTERS_ENCYCLOPEDIA_CN.md) — 完整魔物娘角色图鉴百科（中文原版数据）。
